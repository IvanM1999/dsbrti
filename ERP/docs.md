# DestinyServicesBR OS ERP

## Estrutura do Projeto

- `index.html`: Arquivo principal da aplicação.
- `app.js`: Lógica principal de navegação e carregamento.
- `modules/`: Módulos da aplicação (Clientes, Equipamentos, etc).
- `api/`: Integrações externas (Supabase, PIX, PDF, Backup).

## Executar

1. Instale as dependências: `npm install`
2. Inicie o servidor: `npm start`
3. Acesse: `http://localhost:3000`
