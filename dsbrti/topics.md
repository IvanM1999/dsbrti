Guia de Topics Pré-definidas do GitHub (DSBRTI)
​Para que o script do seu portfólio reconheça e categorize automaticamente seus repositórios públicos, adicione as palavras-chave abaixo na seção About ⚙️ -> Topics de cada projeto no GitHub.
​🤖 1. Automação & Robótica
​Para quais projetos utilizar: Programas em .ino (Arduino, ESP32), C++ embarcado, automação industrial, sensores, garras robóticas e projetos do Wokwi.
​Topics recomendadas: arduino robotica esp32 esp8266 embedded embarcados automacao plc mecatronica wokwi
​📱 2. Mobile & Apps
​Para quais projetos utilizar: Aplicativos nativos para Android/iOS, apps em Kotlin, Flutter, React Native e utilitários móveis.
​Topics recomendadas: kotlin android mobile app ios flutter
​🌐 3. Sistemas & Web SPA
​Para quais projetos utilizar: Aplicações Web em HTML/Vanilla JS, Single Page Applications (SPA), projetos de Lógica de Programação, dashboards e sites.
​Topics recomendadas: html spa frontend web-app pwa web javascript
​💻 4. Software & C++ (Desktop / Backend)
​Para quais projetos utilizar: Programas executáveis desktop, algoritmos em C++, C#, Python, APIs e ferramentas de software puro.
​Topics recomendadas: cpp cplusplus desktop software backend python csharp
​📐 5. Metrologia
​Para quais projetos utilizar: Ferramentas de medição, calibração, controle dimensional, paquímetros/micrômetros digitais e análises estatísticas de tolerância.
​Topics recomendadas: metrologia calibracao medicao instrumentacao tolerancia
​⚙️ 6. Mecânica & Elétrica
​Para quais projetos utilizar: Projetos de CAD, esquemas elétricos, sistemas mecânicos, comandos elétricos e manutenção técnica.
​Topics recomendadas: mecanica eletronica cad eletrica desenho-tecnico
​✅ 7. Qualidade & Processos
​Para quais projetos utilizar: Gestão da qualidade, padronização ISO 9001, diagramas de processo e metodologias industriais.
​Topics recomendadas: qualidade iso9001 processos lean 5s
​💡 Como funciona a prioridade no seu site?
​Combinação Inteligente: Você pode colocar várias topics no mesmo repositório (ex: arduino, robotica, metrologia).
​Prioridade Visual: A primeira topic da lista que coincidir com uma das categorias acima definirá o Card no seu portfólio.
​Fallback por Linguagem: Se você não colocar nenhuma topic, o site identificará a linguagem principal do GitHub:
​Arduino → Vai direto para 🤖 Automação & Robótica
​Kotlin → Vai direto para 📱 Mobile & Apps
​HTML / CSS → Vai direto para 🌐 Sistemas & Web SPA
​C++ → Vai direto para 💻 Software & C++
